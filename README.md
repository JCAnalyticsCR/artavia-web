# Cerrajería Artavia Servicio Express — Landing page

Landing one-page, solo front-end (HTML + CSS + JS sin dependencias). Mobile-first.

## Estructura
- `index.html` — página completa
- `css/styles.css` — estilos
- `js/main.js` — chat interactivo del hero
- `img/` — colocar aquí las fotos reales (ver pendientes)

## Cómo publicar
GitHub Pages: Settings → Pages → Branch `main` / carpeta raíz. No requiere build.
